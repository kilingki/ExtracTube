# ExtracTube

ExtracTube is a prototype project that converts YouTube videos into structured, readable study documents.

## Goal

Turn video content into learning-friendly documents such as:
- structured summaries
- section-based study notes
- book-like readable content

## MVP Scope

- Process a single YouTube URL
- Extract transcript
- Chunk and summarize transcript
- Generate structured study document
- Render results in a web UI
